## 参数调优过程

### 理论分析

```
制导律输出 → 驾驶仪处理 → 实际过载

观察数据：
  - 制导律输出：20g (物理限幅探测通过)
  - 实际过载：48.3g (闭环快扫测试)
  - 放大倍数：48.3 / 20 = 2.415x

结论：
  - 驾驶仪增益约 2.4x
  - 这是合理的（驾驶仪需要响应制导律指令）
  - 不能简单地降低物理限幅探测限制
```

### 参数设置策略

```
策略：
  1. 物理限幅探测限制应该宽松一些
     - 允许制导律输出更高（20-25g）
     - 给驾驶仪更多的响应空间
  
  2. 闭环快扫限制应该更宽松
     - 允许实际过载更高（40-50g）
     - 给优化更多的灵活性

原因：
  - 制导律输出 ≤ 25g
  - 驾驶仪增益 2.4x
  - 实际过载 ≤ 60g
  - 闭环快扫限制 50g
  - 留有 10g 的安全余地
```

## 关键参数说明

### `modify_gate_peak_g` (物理限幅探测限制)

```
作用：
  - 限制 gf() 函数的输出
  - 防止制导律指令过大

设置原则：
  - 太严格：大部分脚本被拒绝，优化失败
  - 太宽松：可能允许不安全的制导律

推荐值：
  - 20-25g：合理的平衡
  - 考虑驾驶仪增益 2-2.5x
```

### `modify_fail_peak_g` (闭环快扫限制)

```
作用：
  - 限制闭环系统的实际过载
  - 防止整个系统过载超标

设置原则：
  - 太严格：闭环快扫失败，优化失败
  - 太宽松：可能允许不安全的过载

推荐值：
  - 40-50g：合理的平衡
  - 考虑制导律输出 20-25g
  - 考虑驾驶仪增益 2-2.5x
```
