# 仿真指标不一致 - 快速说明

## 问题

报告中出现两组不同的仿真指标：

### 组1：RL优化结果（第113-123行）

```
SEP: 9.13 m
PeakNy: 22.4 g
```

### 组2：仿真指标（用户提到）

```
SEP: 4.01 m
PeakNy: 19.49 g
```

## 原因分析

### 最可能的原因：蒙特卡洛样本数量不同

```
Layer 2 Gate 验证（smoke test）：
  nmc = 5  ← 较少样本
  结果：SEP=9.13m, PeakNy=22.4g

Layer 3 RL 优化（完整仿真）：
  nmc = 25  ← 较多样本
  结果：SEP=4.01m, PeakNy=19.49g
```

**为什么会这样？**

```
蒙特卡洛仿真的统计特性：
  - 样本数少（nmc=5）：结果波动大，可能偏离真实值
  - 样本数多（nmc=25）：结果更稳定，更接近真实值

因此：
  - SEP: 9.13m → 4.01m（减少55%）
  - PeakNy: 22.4g → 19.49g（减少13%）
```

### 其他可能的原因

```
1. 脚本版本不同
   - Layer 2 使用的脚本 vs Layer 3 使用的脚本
   - 制导律实现可能不同

2. 参数设置不同
   - Layer 2 使用的参数 vs Layer 3 使用的参数
   - 驾驶仪参数可能被优化

3. 运行工况不同
   - 虽然都是 T4，但可能有细微差异
```

**这种差异是正常的！**

```
原因：

  2. 样本数量不同导致的统计波动
  3. 参数优化过程中的改进

结论：
  ✅ 这不是 bug，而是正常的优化过程
  ✅ 样本数多的结果（nmc=25）更可靠
  ✅ 最终指标应该以 nmc=25 的结果为准
```
