工况路径选择建议0508
徐骁 2026.5.8
一、判断原则
1.	序贯原则：类内按序号递增，前序工况的结论影响后续决策，类间独立；
2.	最可能成功原则：尽量最小代价达标。模板够用不调参，调参能解决不改模型；
3.	超标即升级：任一指标不达标，至少升至路径1；结构性失效（命中率 < 92%），升至路径2。
4.	全局基线优先：PM≈75°、BW偏离目标区间的问题贯穿所有工况，属于弹体-驾驶仪固有特性，建议适当调整弹体参数重跑基线再判断。
二、T类：目标机动模式变化
2.1 T1 匀速直飞：1 调参
原因：命中率100%、SEP3.76m达标，但PM=75.9°超标、BW=8.03r/s偏离目标区间[12,22]。PM和BW是弹体-驾驶仪固有特性，与制导律耦合较弱。
路径1：调导航比和驾驶仪增益即可匹配。
2.2 T2 低频小幅度：1 调参
原因：命中率100%、SEP4.05m达标。同T0，轻微机动对系统无压力。PM/BW属基线问题，PeakNy=7.52g达标。
路径1：调参解决。
2.3 T3 中频中幅：1 调参
原因：命中率99%、SEP4.07m达标，但PeakNy=25.17g超标。T0-T1的经验表明模板在无机动/弱机动下表现良好，但中频机动引入了过载峰值。
路径1：通过降低导航比N或增加加速度限幅可压制峰值过载，代价是SEP略增，但余量充足。
2.4 T4 高频大幅：2 改制导律
原因：最差工况。命中率暴跌至74%，PeakNy=63.08g远超20g上限。T2的调参经验（降低N限幅）在此处不适用。可能是PNG对高频大幅度机动的固有缺陷：加速度指令跟不上目标机动。
T1-T3的经验进一步确认：模板在匀速/低频/中频机动下表现良好。T3的结构性失效说明当目标机动频率超过PNG有效带宽时，可考虑引入补偿比例导引（APN）或含加速度估计的制导律。
三、G类：初始交战几何变化
3.1 G1 标称几何≈21km：0 重用
原因：命中率97%、SEP3.93m、PeakNy=14.59g全部达标。核心指标全绿。PM/BW属全局基线问题非本工况特有。
模板程序可直接用。
3.2 G2 近距小偏置：2 改制导律
原因：命中率71%严重不达标，PeakNy=38.34g超标。BW仅4.2 r/s说明系统带宽严重不足。G0的经验（飞行时间充裕时PNG完全够用）在此处不适用：近距+偏置导致末段时间极短，PNG没有末段增强机制。
可考虑引入增广比例制导或两段式制导。
3.3 G3 近距大偏置：2 改制导律
原因：灾难性结果。命中率22%、SEP=367.85m说明大量样本完全发散。近距大偏置下导弹需要大角度转向，PNG的加速度方向与视线旋转方向存在相位失配。G1的经验（末段带宽不足）进一步恶化：大离轴角导致PNG的线性假设失效。
需引入增广比例制导或最优制导律。
3.4 G4 远距小偏置：0 重用
原因：命中率100%、SEP3.71m、PeakNy=3.07g全达标。
G0的经验在此完全适用：飞行时间充裕，PNG完全够用。模板程序可用。
3.5 G5 远距大偏置：1 调参
原因：PeakNy=121g是所有工况最大值，命中率41%严重不达标。远距大偏置导致长时间飞行+大侧向位移，PNG持续输出侧向加速度→过载饱和。
G1/G4的经验（远距有利）在此处反转：偏置过大导致弹道曲率过高，PNG的侧向加速度指令饱和。可考虑适当加大比例制导的导航系数。
四、AP类：驾驶仪设计参数变化
4.1 AP1 全标称：0 重用
原因：命中率100%、SEP3.88m、PeakNy=4.97g全达标。基线工况核心指标全绿。PM/BW同全局问题。
模板可用。
4.2 AP2 τ单独退化：0 重用
原因：τ从0.20→0.30秒，影响极小。命中率100%、各项指标几乎不变。AP0的经验（模板鲁棒）在此适用：驾驶仪时间常数退化±50%对PNG影响可忽略。
4.3 AP3 轻度退化：1 调参
原因：命中率99%、SEP3.84m达标，但PM=42.3°低于45°下限。AP0-AP1的经验（模板鲁棒）在此处开始失效：驾驶仪带宽下降后，PNG的制导增益与退化后的驾驶仪不再匹配。
路径1：降低导航比或调整增益匹配退化后的带宽。
4.4 AP4 中度退化：1 调参
原因：命中率82%，驾驶仪带宽从50→13 r/s。AP2的经验（增益匹配问题）进一步恶化。BW=13.33仍在[12,22]区间内，但PM=14.0°已严重不足。
路径1：大幅降低制导增益，导航比从默认值下调至2-3。
4.5 AP4 重度退化：1 调参
原因：命中率37%、SEP=275.34m，PM=-7.8°说明系统接近不稳定边界。AP2-AP3的经验（增益匹配）在此处达到极限，应该是驾驶仪问题不是制导律问题。
路径1：将制导增益大幅降低（甚至接近开环），牺牲SEP换取稳定性。
五、R类：气动/质量/推力摄动
5.1 R1 全标称：0 重用
原因：命中率100%、SEP3.91m达标。PeakNy=37.22g超标但这是弹体加速度能力问题，非制导律问题。降低导航比可压PeakNy。
模板可用。
5.2 R2 多参数恶劣：0 重用
原因：恶劣参数下命中率仍100%、SEP4.07m达标。R0的经验在此适用：PNG对气动/质量/推力摄动天然鲁棒，这正是PNG的最大优点。
5.3 R3 大初始姿态：0 重用
原因：命中率100%、SEP3.95m达标。初始姿态偏差被驾驶仪快速修正，PNG几乎不受影响。PeakNy高是因为初始修正消耗的过载，非制导律问题。
模板可用。
