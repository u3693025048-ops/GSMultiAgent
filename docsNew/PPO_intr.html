探索策略

  • 俯仰 w1/zeta1/tao1：初始 log_std=0（σ≈1.0）
  • 其余维度：log_std=−1（σ≈0.37）
  • Episode 衰减：decay=max(0.15, 1−ep/max_ep)，log_std ← base+log(decay)
  • 自适应探索（v0.4.0）：AdaptiveExplorationController 按 reward EMA、参数步长缩放 log_std（exploration.adaptive_*）；低 reward / 发散时收缩至 adaptive_log_std_min_scale

4. 奖励函数

4.1 结构

  • 硬截断：PeakNy>50g 或 SEP/PeakNy NaN/Inf → HARD_REWARD_PENALTY = −10
  • Fallback：_sim_source=fallback 时仅 SEP 负项
  • Phase A：SEP > sep_survival_threshold（500m）— 无 hit/PM/BW
  • Phase B：完整分项；PM/BW × _fine_scale = max(0, 1−SEP/threshold)
RSEP = − clip(SEP/1000, 0, 10)  （两阶段均有）

4.2 PeakNy 软约束

超出 peak_ny_max（20g）按 overshoot 分段惩罚；读取优先 get_peak_ny_max()（MC max），其次 peak_ny 均值。权重 peak_ny_penalty（顶层 peak_n_penalty=2.5 覆盖）。

4.3 异常 SEP

统一经 _compute_reward；NaN SEP 硬截断；跳过 best 更新但参与 PPO batch；batch 满 64 仍触发更新。

5. PPO 更新

  1. G = R（γ=0）
  2. A = G − V(s)，batch 内标准化
  3. clip ratio ε=0.15；entropy_coef=0.05
  4. 梯度累积后单次 Adam；grad clip ±0.5
  5. 熵 bonus 每 batch 更新 log_std 一次
