design_path_policy.py策略函数should_use_modify_law、apply_reflection_policy、should_skip_layer3_param_search

3. tools 子模块（Hermes 可调用）

  • rag_tool.py — retrieve / expand / agent 检索
  • simulation_tool.py — run_simulation、脚本 sanitize、PE 检索；last_metrics 供 cli Gate / 复核
  • syntax_check_tool.py — LLM 驱动 MATLAB 语法迭代修正
  • compatibility_tool.py — verify_guidance_compat（gf→驾驶仪适配性推导）
  • judge_requirements_tool.py — 规则+LLM 判据；PeakNy 以 peak_ny_max 为准；输出 metrics_summary 含 mean/max
  • parameter_experience_tool.py — pe_search / pe_store / pe_best
  • delegate_tool.py — call_specialist 路由子智能体

注意：RL 优化不在 Hermes 工具集中，仅 Layer 3 OptimizationWorkflow 直接调用 MatlabRLOptimizer。

4. 模块依赖图

flowchart TD CLI[cli_agent.py] --> CFG[config_loader] CLI --> HERMES[hermes_integration] CLI --> OWF[optimization_workflow] CLI --> PE[parameter_experience] CLI --> RAG[rag_knowledge_base] HERMES --> TOOLS[tools/*] TOOLS --> SIM[guidance_simulator] OWF --> RL[matlab_rl_optimizer] OWF --> JUDGE[judgment_agent] OWF --> REFL[reflection_agent] RL --> SIM PE -.-> TOOLS RAG -.-> TOOLS

5. RL 模块要点

  • ALL_TUNABLE_PARAM_SPECS：8 驾驶仪 + N_pn = 9 维
  • parse_sim_stdout：统一 MATLAB 输出解析（RL 与 cli 共用）
  • get_peak_ny / get_peak_ny_max / get_sep：指标别名统一读取（安全约束用 max）
  • AdaptiveExplorationController：按 reward EMA 动态缩放探索噪声
  • Contextual Bandit：γ=0，batch=64，无 GAE

6. 智能体职责边界与防护

组件允许禁止
ReflectionAgent / JudgmentAgent输出 next_action、rl_hyperparams、诊断文本调用 Hermes 工具、直接 run_simulation
OptimizationWorkflow (Expert)LLM 建议 → clamp_tunable_params → 仿真接受未校验的物理量键（air_density 等）
cli_agent 主循环接收 Reflection JSON，驱动 Layer 2/3让 Reflection 隐式回调仿真（星型拓扑）
MatlabRLOptimizer动作映射至 ALL_TUNABLE_PARAM_SPECS 边界内执行 LLM 自由文本参数
