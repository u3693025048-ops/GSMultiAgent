3. PPO 实现选型

  • Contextual Bandit：每 episode 独立仿真，无跨步 MDP → γ=0，Returns=R
  • 有界绝对寻优：param = mid + a×half，非 baseline 残差
  • batch=64：稳定梯度；nmc_per_eval=10 平衡耗时与方差
  • entropy_coef=0.05：防探索塌缩；episode 级 log_std 衰减
  • AdaptiveExplorationController（v0.4.0）：按 reward EMA / 参数步长动态缩放 log_std（exploration.adaptive_*）

4. Judge、Gate 与指标解析

  • parse_sim_stdout：从 MC 输出分离 peak_ny（均值）与 peak_ny_max（max=XXg）
  • run_simulation.last_metrics：仿真工具缓存解析结果；cli Gate 与复核优先使用
  • judge_requirements_tool._rule_check：有 peak_ny_max 时以 max 判 PeakNy；硬约束失败时 LLM 不得翻案
  • cli_agent：进 Layer3 前对 hermes_sim_metrics 再跑 _rule_check，纠正 judge/LLM 手填与 stdout 不一致（log06102355 类回归）
  • layer2_script_gate：T4 MODIFY 闭环 modify_gate_nmc；modify_gate_peak_g=30 为 Gate 上限（任务指标仍 ≤20g）
  • should_gate_near_miss_tune：Gate 拦截但 peak 在 (20,30]g 且 hit/SEP OK → 同轮 TUNE 进 Layer3
  • get_peak_ny_max()：RL 奖励、Gate、规则检查统一读取入口

6. 技术风险与缓解

R1 MATLAB 启动慢 — 使用 matlab_engine 热会话；RL 剥离 plot 调用；stale metrics 检测后切换 subprocess。
R2 仿真 stdout 解析失败 — 多模式 regex + LLM fallback；诊断日志 dump；内部 fallback 仅 SEP 奖励。
R3 LLM 幻觉脚本 — syntax_check 迭代；verify_guidance_compat；interface_check 文件。
R4 Reward hacking (T4) — Phase A 禁 PM/BW；硬截断 PeakNy>50；T4 低风险策略限制 MODIFY 后 PPO；自适应探索低 reward 收缩。
R7 MODIFY gf 过载爆炸 — physics_bounds 桩探测；T4 内置 tanh+clip 20g APN；MODIFY 失败禁 TUNE。
R5 Windows asyncio — SelectorEventLoopPolicy；子进程替代 async pipe。
R6 API 密钥泄露 — 应使用 .env；勿将真实 key 提交仓库（见安全设计）。
R8 LLM 毒药参数 — clamp_tunable_params + sanitize_rl_hyperparams；禁止物理量键；PPO 动作有界映射。
R9 并发仿真文件冲突 — TaskWorkspace 每任务独立目录 + episode 级 rltmp_{uuid}。
R10 双标尺指标 — Hermes judge 可能手填 metrics；cli 以 stdout 解析 + Gate 闭环 metrics 为准；部署时同步 judge_requirements_tool 与 cli_agent 复核逻辑。
R11 Gate 误拦/漏拦 — modify_gate_peak_g 与任务 20g 分离；peak>30g 必须继续 MODIFY；20–30g 可 near-miss TUNE；多项崩盘（hit/SEP 失败）不触发 near-miss。
R12 MATLAB 长仿真超时 — matlab_timeout_sec / matlab_timeout_per_mc_sec；Gate smoke + MODIFY 闭环需足够 Nmc 与 timeout。
