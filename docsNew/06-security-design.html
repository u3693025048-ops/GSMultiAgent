1. 密钥与凭证管理

项实现建议

警告：切勿将含真实 API Key 的 config.yaml 提交公开仓库。

2. 子进程与命令执行

  • MATLAB/Octave 通过 subprocess.Popen，非 shell=True
  • 脚本路径绝对化；工作目录限定为脚本所在目录（沙箱内则为 UUID 目录）
  • 超时：MATLAB_TIMEOUT_SEC（默认 1200s）
  • RL 临时脚本 rltmp_*.m 在 finally 删除；启动 sweep stale
  • Python 3.13+ 跳过 MATLAB Engine API

3. 文件路径与写入边界

目录用途约束
guidance_output/scripts/Hermes 持久化脚本共享区；Layer 3 执行前拷贝至 tasks 沙箱
guidance_output/tasks/{uuid}/TaskWorkspace 临时沙箱迭代结束自动删除；24h stale sweep
parameter_experience_base/PE JSON + 模型副本跨会话持久化
chroma_db/向量索引本地 SQLite
logs/运行日志可能含 prompt，共享前脱敏

4. Prompt 注入与 LLM 安全

  • 用户 prompt 进入 Hermes 上下文 — 可能诱导工具误调用
  • 缓解：Tool schema 限定参数；仿真仅接受 .m 路径；不执行任意 shell
  • MATLAB 脚本经 _sanitize_matlab_guidance_script 静态清理
  • Reflection / Judgment 输出不直接 eval 代码

5. 参数防火墙（ParameterFirewall）

模块：multi_agent/security/parameter_firewall.py

函数调用点行为
clamp_tunable_paramsExpert Tuning（optimization_workflow.py）9 维白名单；每维 ALL_TUNABLE_PARAM_SPECS min/max clamp；拒绝 air_density 等物理键
sanitize_rl_hyperparamsReflection 后处理、cli_agent 存储 override14 个 RL 超参/奖励权重有界；未知键丢弃；非有限数跳过
apply_rl_hyperparams_to_optimizercli_agent Layer 3 入口校验后写入 MatlabRLOptimizer
ParameterFirewallViolationstrict=True 模式毒药参数抛异常（Expert 默认 warn+clamp）

RL 超参合法范围（与 Reflection prompt 一致）

  • lr_actor 1e-5~1e-2 · lr_critic 1e-5~3e-2 · clip_ratio 0.05~0.4 · gamma 0.90~0.999
  • max_episodes 10~150 · nmc_per_eval 5~50
  • 奖励权重：hit_rate_weight 0.5~10；sep_* 0~8/0~5；pm/bw_* 0~4/0~8；peak_ny_penalty 0~8
已实现：PPO 动作空间本身有界（_action_to_params）；防火墙覆盖 Expert/Reflection 的 JSON 路径，形成双保险。
MODIFY_LAW 缓解（v0.4.1）：physics_bounds.py 桩探测；T4 内置 APN（tanh+20g）；layer2_script_gate 闭环 PeakNy Gate（modify_gate_peak_g）；near-miss 时同轮 TUNE 而非盲目重跑 MODIFY。Judge/cli 以 stdout 解析指标为准。

5b. gf() 物理限幅探测（Physics Bounds）

模块：multi_agent/simulation/physics_bounds.py

函数调用点行为

5c. T4 低风险策略（业务安全）

模块：multi_agent/integration/t4_low_risk.py，配置 t4_low_risk.*

  • MODIFY_LAW：确定性 GF_APN_T4_MINIMAL（PN + 0.45 前馈 + LPF + 20g 限幅），跳过 LLM 自由重写
  • 保守 autopilot：w1/w2/w3≈35、N_pn≈3.5；上限 w≤45、N_pn≤4.5
  • MODIFY 后 peak>30g 或 hit<85% → 禁止 TUNE，强制重做 MODIFY
  • post-MODIFY 首轮 Layer3 强制 Expert，PPO episode ≤50
  • Planner / Reflection prompt 注入硬约束，覆盖 LLM 与历史失败冲突的建议

6. 任务沙箱（TaskWorkspace）

模块：multi_agent/simulation/task_workspace.py

  • 每轮 Layer 3：with TaskWorkspace() as ws: 创建 guidance_output/tasks/{uuid}/
  • prepare_script(src.m) 拷贝脚本至沙箱；RL 在该目录生成 rltmp_{hex}.m
  • 上下文退出时 cleanup() 删除整个 UUID 目录
  • 启动时 TaskWorkspace.sweep_stale(max_age_hours=24) 清理遗留沙箱
目的：避免多任务/多迭代并发时 MATLAB 临时文件与编译缓存在同一目录相互覆盖。

7. 智能体职责边界（星型拓扑）

角色输出不得持有

JudgmentAgentJSON：satisfied, reasons改参、跑仿真

8. 异步任务与 HTTP 集成（已实现）

模块：multi_agent/async/task_queue.py、http_server.py

CLI 参数作用
--async-run后台启动子进程 cli_agent，立即返回 task_id
--task-status ID轮询任务状态、PPO episode 进度、最终结果路径
--serve-tasks启动 HTTP 服务（默认端口 8765），POST/GET /tasks
  • 子进程通过环境变量 GSMULTI_TASK_ID 回写进度；PPO progress_callback 更新队列
  • 解决外部编排器 60~300s HTTP 超时与长 PPO（100 ep × batch 64）阻塞问题
  • 消融开关仍可禁用 RL 等扩大攻击面组件
已实现：单机 CLI + 可选 HTTP 轮询；Webhook 推送可在外部网关层扩展。
