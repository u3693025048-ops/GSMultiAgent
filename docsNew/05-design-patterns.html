2. 工具模式（Hermes Tool）

classDiagram class BaseTool { +name: str +description: str +input_schema: dict +execute(args) async } class SimulationTool { +run_simulation } class RAGTool { +rag_retrieve } BaseTool <|-- SimulationTool BaseTool <|-- RAGTool

工具通过闭包捕获 simulator、pe、task_prompt 等上下文，避免全局变量。

3. 配置 Dataclass 模式

config_loader.AppConfig 聚合：

  • AblationConfig — 消融开关
  • MatlabRLOptimizerConfig + RLRewardConfig
  • LLMConfig / RAGConfig / SimulationConfig
  • T4LowRiskConfig — T4 低风险 playbook（config.yaml → t4_low_risk）
  • RLExplorationConfig — PPO 探索 + adaptive_* 自适应缩放

RLRewardConfig.to_dict() 传入 MatlabRLOptimizer(reward_weights=...)；顶层 peak_n_penalty 覆盖 reward 权重。

4. RL 中的模式

  • Contextual Bandit：无环境状态转移，每步独立 (s,a,R)
  • Experience Replay（批内）：64 episode 缓冲后 PPO 更新
  • Reward Shaping：Phase A/B 分阶段 + 硬截断
  • Early Stopping：Reflection 观察者模式介入主循环
  • Adaptive Exploration：奖励平台/发散时动态收缩 log_std（与 episode 衰减叠加）

5. 安全防护模式

  • 纵深防御：PPO 有界动作 + Expert clamp + gf physics_bounds + T4 确定性 APN + Reflection 超参 sanitize
  • 最小权限：诊断智能体无 Tool Schema；RL 不在 Hermes 工具集
  • 失败安全：非法键丢弃并日志告警；strict 模式可抛 ParameterFirewallViolation
