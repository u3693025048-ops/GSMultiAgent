## 根本原因分析

### 可能的原因

```
1. 不同的蒙特卡洛样本数量
   - 组1：可能使用较少的样本（如 nmc=5 smoke test）
   - 组2：可能使用较多的样本（如 nmc=25）
   - 结果：统计波动导致指标不同

2. 不同的脚本版本
   - 组1：使用的脚本版本 A
   - 组2：使用的脚本版本 B
   - 结果：制导律实现不同，指标不同

3. 不同的运行工况
   - 组1：运行工况 A（如 RUN_CASE='T', SUB_IDX=4）
   - 组2：运行工况 B（如 RUN_CASE='T', SUB_IDX=3）
   - 结果：工况不同，指标不同

4. 不同的参数设置
   - 组1：使用参数集 A
   - 组2：使用参数集 B
   - 结果：参数不同，指标不同

5. 报告生成时的数据混淆
   - 组1：来自 Layer 3 RL 优化的结果
   - 组2：来自 Layer 2 仿真的结果
   - 结果：两个不同阶段的数据被混在一起
```

## 详细分析

### 分析1：蒙特卡洛样本数量

**Layer 2 Gate 验证**（smoke test）：
```
layer2_smoke_nmc: 5  # ← 较少的样本
```

**Layer 3 RL 优化**：
```
nmc: 25  # ← 较多的样本
```

**结果**：
- 组1（RL优化）可能使用 nmc=5 的 smoke test
- 组2（仿真指标）可能使用 nmc=25 的完整仿真
- 样本数量不同导致统计结果不同

### 分析2：脚本版本

**报告中提到的脚本**：
```
生成脚本: guidance_simulation_T4_MODIFY_LAW_1781107289.m
```

**可能的问题**：
- 脚本在 Layer 2 和 Layer 3 之间可能被修改
- 或者使用了不同版本的脚本
- 导致仿真结果不同

### 分析3：运行工况

**报告中指定的工况**：
```
运行工况：RUN_CASE='T'; SUB_IDX=4;
```

**可能的问题**：
- 组1 和组2 可能运行了不同的工况
- 或者同一工况但参数不同
- 导致指标不同
