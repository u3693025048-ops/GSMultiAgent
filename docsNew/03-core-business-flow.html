2. TaskPlanner 三种模式

模式触发条件行为
REUSE_HISTORYPE 已有足够优参数直接加载历史最优 dp_* 仿真，跳过生成
TUNE_PARAMS结构 OK、需调参生成脚本 → 校正 → 仿真 → Layer 3
MODIFY_LAW需改制导律结构 / T4 4/5 仅 peak 超标RAG → 改 gf()（T4 可用内置 APN 模板）→ physics_bounds → 兼容/语法 → 仿真

3. Layer 3 策略选择

OptimizationWorkflow._select_strategy() 读取 config.yaml → matlab_rl_optimizer.layer3_strategy，并叠加 t4_low_risk 与 design_path_policy 覆盖：

策略行为
expertLLM 引导多轮专家调参（默认 5 轮，nmc≈30）；不足则 fallback PPO
ppo直接 MatlabRLOptimizer.optimize()
auto按失败指标数量启发式或 LLM JSON 选择 expert/ppo
T4 post-MODIFYshould_force_expert_after_modify → 首轮强制 Expert，PPO episode 上限 50
4/5 仅 peakshould_skip_layer3_param_search → 跳过 Expert/PPO，next_action=modify_law
MODIFY 灾难性失败peak>30g 或 hit<85% → should_block_tune_after_bad_modify 禁止 TUNE

4. Layer2 Gate 与 near-miss TUNE（v0.4.1）

在 Hermes 仿真与 Layer3 之间，cli_agent.py 调用 ensure_script_ready_for_layer3 做结构化门禁：

flowchart TD A["Hermes: generate + run_simulation"] --> B["cli: _rule_check 复核 metrics"] B --> C{"directly_satisfied?"} C -->|是| D["跳过 Layer3 RL"] C -->|否| E["Layer2 Gate"] E --> F["syntax + validate_rl_script"] F --> G["smoke nmc=layer2_smoke_nmc"] G --> H{"MODIFY_LAW + T4?"} H -->|是| I["闭环快扫 nmc=modify_gate_nmc"] I --> J{"PeakNy_max ≤ modify_gate_peak_g?"} J -->|否| K["BLOCK Layer3"] K --> L{"should_gate_near_miss_tune?"} L -->|20g < max ≤ 30g 且 hit/SEP OK| M["同轮 TUNE_PARAMS → Layer3"] L -->|否| N["continue → 下轮 MODIFY"] J -->|是| O["Gate PASS → Layer3"] H -->|否| O

near-miss 条件：task_mode=MODIFY_LAW、T4 工况、Gate 因 peak 拦截，且 peak_ny_max 在 (20g, 30g]、命中率与 SEP 已达标 → 不切回外层 MODIFY，而是本轮以 TUNE_PARAMS 进入 Layer3 Expert/PPO。

8. ParameterExperience 晋升

  • task_requirements_met → LONG_TERM 记忆
  • 普通 success → SHORT_TERM，后续可 auto_promote
  • 模型副本：parameter_experience_base/models/{short,long}_term/
  • 与 Chroma RAG 分离：PE 参数 JSON 不混入向量索引

9. 防护嵌入点（流程内）

flowchart TD R[ReflectionAgent JSON] --> FW[sanitize_rl_hyperparams] FW --> L1[cli_agent 下一轮 Layer 3] E[Expert LLM JSON] --> CT[clamp_tunable_params] CT --> SIM[run_simulation] L1 --> TW[TaskWorkspace UUID 目录] TW --> L3[OptimizationWorkflow.run] L3 --> RL[rltmp_uuid.m 临时脚本]
  • 每轮 Layer 3 前：TaskWorkspace.prepare_script() 拷贝 .m 至独立沙箱
  • Expert 每轮：LLM 输出 JSON → clamp_tunable_params（9 维白名单 + min/max）
  • Reflection 返回：_postprocess_reflection → reward 权重等有界校验
  • MODIFY_LAW：physics_bounds 桩探测 gf() 输出；T4 clamp_autopilot_params 限制 w/N_pn
  • Judge / cli 复核：peak_ny_max 硬约束；cli 对 run_simulation 解析指标做 _rule_check，与 Hermes judge 结果交叉校验
  • Layer2 Gate：MODIFY 后 peak>30g 或 hit<85% 禁止进 RL；20–30g 近失配可走 near-miss TUNE
  • 异步：--async-run 子进程写 task 状态；PPO progress_callback 回写 episode

10. 异步 CLI 用法

python cli_agent.py --async-run --prompt "RUN_CASE='T'; SUB_IDX=4; ..."
python cli_agent.py --task-status <task_id>
python cli_agent.py --serve-tasks --task-port 8765

HTTP 服务提供 POST /tasks、GET /tasks/{id}，供外部编排器轮询长 PPO 任务。
